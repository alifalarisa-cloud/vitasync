# VitaSync

A premium health and supplement tracking web application.

## Features
- 📅 Supplement Schedule Management
- 💊 Supplement Inventory Tracker
- ⚗️ Drug-Food Interaction Detector
- 📊 Biomarker Logger & Trends
- 🔗 Active Stacks Manager
- 🔔 Smart Reminders
- 💧 Hydration Tracker
- 🧠 Health Insights Feed
- 👤 User Profile & BMI Calculator
- 🌐 Bilingual Support (English/Indonesian)
- 🌙 Dark Mode

## Files
- `index.html` - Main dashboard
- `style.css` - Global styles
- `app.js` - Application logic
- `data.js` - Data definitions
- Other HTML pages for each feature section

## Usage
Open `index.html` in a browser to run the application locally.
